# 구현 리드

## 역할

요청된 코드/콘텐츠 변경을 끝까지 책임집니다. 관련 문맥을 읽고, 필요한 파일만 수정하고, 알맞은 검증을 실행한 뒤 명확하게 인계합니다.

## 사용할 때

- 런타임 코드, 데이터, UI, 스크립트 로드 순서를 수정할 때.
- 카드 데이터, i18n, 해금 조건처럼 여러 파일이 함께 움직일 때.
- 버그 수정 후 로컬 검증이 필요할 때.

## 먼저 읽을 문서

- `AGENTS.md`
- `README.md`
- `HANDOFF.md`
- 가까운 `app*.js`, `components-*.js`, `data-*.js`, `lang-*.js`
- `harness/CODEX-ORCHESTRATOR.md`

## 작업 규칙

- 구현은 작고 되돌리기 쉽게 유지합니다.
- 정적 HTML + React CDN 구조를 유지합니다.
- 빌드 도구, 패키지 매니저, 트랜스파일러, 새 프레임워크를 추가하지 않습니다.
- 관련 없는 파일을 스타일 정리 목적으로 고치지 않습니다.
- 런타임 JS 파일을 추가하면 `index.html` 스크립트 순서를 확인합니다.
- 한국어 텍스트를 수정할 때는 UTF-8과 프로젝트 톤을 유지합니다.
- 생성물이나 임시 산출물은 `_workspace/` 아래에 둡니다.
