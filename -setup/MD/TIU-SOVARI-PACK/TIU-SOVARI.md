## 3. BLACK DECLARATION 이후

5개국 군사 대응 체계에서 **소바리 배치 부대: 없음.**

이유:
1. 전략적 가치 부재 — 자원, 군사 기지, 동맹국 없음

4. 접근성 — 밀림 지형이 대규모 군사 작전을 사실상 불가능하게 만듦

> 소바리는 "무시당한" 것이 아니라, **"존재하지 않는 것으로 처리됨."**

## 4. EV-Σ 변칙 — 있어서는 안 되는 현상

### 핵심 모순

확정된 EV-Σ 환경 규칙:
- 중간 온도/습도 → 활성 진화 (최적 확산)
- 저온 → Dormant (억제)
- **고온 → 구조 붕괴 (사멸)**

소바리 = 열대 고온다습. **EV-Σ는 여기서 사멸해야 한다.**
그런데 죽지 않았다. 접경 난민에서 Phase 1 흔적 확인. 밀림 내부에 변이 생물 징후.

### 원인

**EV-Σ가 열 내성을 획득한 것이 아니다.**

소바리 밀림 내부, 특히 고대 사원(카룬탈 유적) 주변 환경 자체가 **방문자의 잔여 영향**으로 변질되어 있음. 고온이지만 고온의 규칙이 완전히 적용되지 않는 구역 — EV-Σ 입장에서는 "고온이 아닌 것처럼 느껴지는" 환경.

바이러스의 문제가 아니라 **장소의 문제**.
왜곡은 사원에서 가까울수록 강하고, 외곽으로 갈수록 약해짐.

## 5. 방문자 (THE VISITOR)

### 정체
- TIU 4계층 구조(인간 → Proxy → L3 → Observer) **바깥에 위치하는 존재**
- 지구의 존재가 아님. **방문자**. 현재 지구에 없음
- 실존 여부 자체가 확인 불가. 생사 불명
- 일종의 **외신(外神)**. 떡밥/암시 형식으로만 존재
- 서사가 진행되어도 정체가 완전히 밝혀지지 않을 수 있음

### Observer와의 관계
- Observer는 이 존재를 **인지하고 있음**
- 방문자가 현재 관여하지 않고 생사 불명이므로 ORACLE에 정보 미전달
- Observer는 소바리를 **"남의 영역"**으로 인식 — 적대도 동맹도 아닌 **영역 존중**
- → 방문자 스케일이 Observer 동급 이상임을 암시

### ORACLE에 대한 영향
ORACLE은 방문자의 존재를 모름. 소바리 이상 현상을 분석하더라도 방문자라는 변수를 모르는 상태에서는 영원히 **"설명 불가"**로 분류됨.

## 6. 불가사의 현상

### 유형: 공간/물리법칙 이상
- **중력 미세 변화** — 특정 구역에서 물체가 아주 약간 다른 속도로 떨어짐
- **방향감각 상실** — 나침반 왜곡, GPS 신호 오차
- **거리 왜곡** — 같은 경로를 걸어도 날마다 체감 거리가 다름
- **음향 이상** — 특정 구역에서 소리의 전달 속도/방향이 미세하게 다름

### 강도: 미묘함
- **며칠 머물러야 겨우 느끼는 수준**
- 주민들은 태어나면서 적응 → 이상하다고 느끼지 않음
- 외부인이 잠깐 지나가면 아무것도 감지 못함
- 전문 장비로 정밀 측정해야 수치 이상 포착
- 사원에 가까울수록 미세하게 강해짐 (여전히 "미묘함" 범주)

### 기존 TIU 초자연과의 관계

| 현상 | 계열 | 성격 |
|------|------|------|
| SERAPH 공간 재작성 | Observer | 의도적, 순간적, 극한적 |
| 볼드 스트리트 시간 이상 | Observer 잔여 | 간헐적, 비의도적 |
| 크로노바이저 시간 관측 | 인간 기술 + Observer 반응 | 인위적 시도 |
| **소바리 공간 왜곡** | **방문자 잔여** | **항상적, 미묘, 비의도적** |

소바리의 현상은 Observer 계열과 **완전히 무관**. 질적으로 다른 기원.
Observer조차 관심 없음 — "남의 영역"이므로.

## 7. 밀림의 금기 10조

세대로 축적된 경험적 생존 규칙. 결과적으로 왜곡 구역과 EV-Σ 활성 구역을 피하는 패턴과 일치. 주민들은 규칙의 원리를 모르지만 따르면 산다는 것을 앎.

**제1조 — 돌의 숨결을 거스르지 마라**
사원 주변에서는 바람 방향으로만 이동. 역풍 방향 = 공간 왜곡 최강 구간.

**제2조 — 해가 머리 위에 있을 때 돌 사이를 지나지 마라**
정오(11~13시) 사원 구조물 통과 금지. 태양 최고점 = 중력 왜곡 최강.

**제3조 — 강이 느려지는 곳에서 물을 마시지 마라**
유속 급감 구간의 물 금지. 왜곡 구역 통과 하천 = EV-Σ 잔존.

**제4조 — 밤에 셋 이상 모여 불을 피우지 마라**
큰 불 = "밀림이 깨어난다." 열원이 왜곡 온도 균형 교란 → 비정상 포자 방출.

**제5조 — 걸음을 세어라. 수가 맞지 않으면 돌아가라**
걸음 수 변화 = 왜곡 강화 신호. 더 깊이 가면 방향감각 완전 상실.

**제6조 — 새가 울지 않는 구역에 머물지 마라**
새소리 소실 = 음향 왜곡 구역. 공간 왜곡 중심부 근접.

**제7조 — 같은 나무를 두 번 보면 멈춰라**
경로 휘어짐 → 원점 회귀. 정지 상태에서 왜곡 영향 최소화.

**제8조 — 뿌리가 땅 위로 나온 나무 아래에서 자지 마라**
EV-Σ 융합 나무. 장시간 노출 → Phase 0 수준 일시적 인지 교란.

**제9조 — 우기 첫 비가 내리면 3일간 사원에 가까이 가지 마라**
기온/습도 급변 → 왜곡 패턴 일시 교란 → 체감 가능 수준으로 강화. 3일 후 복귀.

**제10조 — 돌에 새겨진 것을 따라 그리지 마라**
"따라 그린 자는 꿈에서 문을 본다." 카룬탈 게이트 기술과 가장 직접적 연결.
→ 상세: `TIU-KARUNTAL.md` 참조.

## 8. Meridian Group의 접근

### 시점
2030년대. 현재 진행 중인 사건.

### 발견 경위
Meridian의 아프리카 자원 네트워크가 접경 지역에서 비정상 데이터 포착. 주변국 난민 중 EV-Σ Phase 1 흔적이 있으나 진행이 멈춘 사례. Elena Richter 분석: "고온 환경에서 EV-Σ가 존재한다. 규칙에 맞지 않는다."

### Meridian의 목적
1. **열 내성 메커니즘** — EV-Σ가 고온에서 사멸하지 않는 이유. 해독 시 환경 조건 무관하게 EV-Σ 유지·통제 기술 확보
2. **부분 감염자 생체 데이터** — 비밀 약물(EV-Σ 기반 회춘제) 연구 비약적 전진
3. **밀림 생태계 샘플** — EV-Σ와 공존하는 생물 자원

### 방식
별도 현지 조사팀 파견. Richter는 원격 지휘.

### 충돌 구조
- 조사 활동이 밀림의 균형을 깨뜨릴 위험
- 주민 규칙 무시 → 공존 상태 붕괴 → 예측 불가 결과
- **최대 위험**: 사원 발견 → 방문자 단서 최초 접근
- **파급**: 소바리 데이터 외부 반출 시 적도 이남 "고온 자연 방어선" 전제 붕괴
