# TIU-L3-LANGUAGE.md

## KETH'VAAR (케스바르) — L3 명명 언어 체계

**문서 범위:** A안 (명명 언어). 음운 규칙 + 핵심 형태소 + 기존 용어 역분석 + 생성 가이드.
**용도:** L3 고유명사, 기관명, 지명, 의식 문구 단편의 일관성 유지.
**비고:** 본 문서는 참조용 카탈로그. 실용 회화·문법 전체는 다루지 않음.

---

## 1. 언어 개요

| 항목 | 내용 |
|---|---|
| 언어명 (원어) | KETH'VAAR (케스바르) |
| 어원 | KETH(중심) + VAAR(말) → "중심의 말" |
| 화자 | L3 파충류 문명 전체 (수도 KETH'ARUN 기준 표준어) |
| 현재 상태 | 활어 (L3 내부 공용어) |
| 고대층 | 의식·서약·용 제례 기록에 사어화된 고형(古形) 잔존 |
| 인간 인지도 | 거의 없음. EXUVIA·ORACLE 접점 기록에만 단편 노출 |

## 2. 음운 규칙

### 2.1 자음 (10 + 1)

| 범주 | 음소 | 표기 |
|---|---|---|
| 폐쇄음 | /k/, /t/ | K, T |
| 마찰음 | /v/, /s/, /θ/, /x/ | V, S, TH, KH |
| 유음 | /r/, /l/ | R, L |
| 비음 | /n/, /m/ | N, M |
| 성문 폐쇄음 | /ʔ/ | `'` (아포스트로피) |

### 2.2 모음 (5)

| 음소 | 표기 | 장모음 |
|---|---|---|
| /a/ | A | AA |
| /e/ | E | EE |
| /i/ | I | II |
| /o/ | O | OO |
| /u/ | U | UU |

### 2.3 음절 구조

- 기본형: **(C)(C)V(C)**
- 허용 어두 자음군: `VR-`, `SS-`, `STR-`, `KH-`, `TH-`
- 금지: 어말 자음군, 3중 자음군, 모음 연속(동일 장모음 제외)

### 2.4 강세

**끝에서 두 번째 음절 고정.**
- SSEV-**RATH** / KETH'A-**RUN** / VRE-**THOL** / SOL-**VEK**

### 2.5 아포스트로피 `'`의 이중 역할

1. **형태소 경계 표시** — 복합어에서 의미 단위 구분 (VRETH**'**OL = VRETH + OL)
2. **성문 폐쇄음 [ʔ]** — 실제 발음 존재. 짧은 숨 끊김.

## 4. 기존 캐논 용어 역분석

| 용어 | 분해 | 축자 의미 | 캐논 역할 | 정합성 |
|---|---|---|---|---|
| SSEVRATH | SSEV + RATH | 탈피의 길 | 쉐드 오더 (L3 내부명) | ✅ |
| VRETH'OL | VRETH + OL | 등껍질의 일족 | 거북파 자칭 | ✅ |
| VETH'SAAN | VETH + SAAN | 살아있는 혈통 | 중립 생존파 | ✅ |
| NURATH'KA | NU + RATH + KA | 응시의 길을 가는 자들 | 관찰자파 | ✅ |
| KETH'ARUN | KETH + ARUN | 중심의 땅 | L3 수도 | ✅ |
| VRAETH | VR + AETH | 전투의 명예 | 전투 간부 | ✅ |
| SOLVEK | SOL + VEK | 보는 자/아는 자 | 정보 간부 | ✅ |
| CATHARI | CATH + ARI | 말의 연장자 | 정치 간부 | ✅ |
| VAREK | VAR + EK | 지키는 자 | 거북파 대표 | ✅ |
| EXUVIA | (라틴어) | — | **인간 측 코드명** | ⚠️ L3 원명 별도 |

### 4.1 EXUVIA의 L3 원명 (확정)

- **VETHARI (베사리)** = VETH + ARI = "살아있는 연장자"
- 채택 근거: 수천 년 생존 + 마지막 전쟁 생존자 설정과 의미 정합
- 사용 방침: L3 내부 기록·EXUVIA 직접 지칭 장면에서 사용. 인간 문서에는 EXUVIA 유지.
- 인간 측에 VETHARI라는 이름은 **노출되지 않음** (ORACLE/프로메테우스도 인지 못함)
- 언어적 특수성: 드래곤 관련 고대층(사어)을 정확히 이해하는 **유일한 현존 L3**. → §6.1 참조

## 5. 생성 규칙 (신규 용어 만들 때)

### 5.1 생성 절차

1. 전달하고자 하는 **의미 축** 결정 (어근 선택)
2. 문법적 **역할 결정** → 접미사 선택
3. 음운 규칙 적용 (강세·자음군 검증)
4. 발음 용이성 확인 → 한글 표기 병기
5. 기존 용어와 충돌 없는지 점검

### 5.2 생성 예시 (검증 완료)

| 생성어 | 분해 | 의미 | 용도 예시 |
|---|---|---|---|
| CATHARUN (카사룬) | CATH + ARUN | 말의 땅 | 협약·외교 거행지 |
| SOLARI (솔라리) | SOL + ARI | 아는 연장자 | 지식 담당 장로 |
| VRETHKA (브레스카) | VRETH + KA | 등껍질의 자들 | 거북파 일반 구성원 |
| SSEV'VEK (쎄스벡) | SSEV + VEK | 벗어내는 자 | 쉐드 오더 입문자 |

### 5.3 금지 패턴

- `*OLRATH` (모음 없는 자음군 충돌)
- `*AEIOU` (3모음 이상 연속)
- `*-OL-OL` (동일 접미 반복)
- `*KETHEXUVIA` (라틴어계 어근 혼용)

## 6. 고대층 (사어화된 층위)

의식·서약·제례 기록에만 남은 고형(古形). 현재 L3 화자도 단편만 이해.

- **용 숭배 잔존 문구** (지정 미완)
- **협약 서약 고어** (지정 미완)
- **VETHARI 선언 포맷** (지정 미완)

### 6.1 VETHARI의 용 사어 독점 지식

**VETHARI(EXUVIA)는 용 관련 사어층을 정확히 아는 유일한 L3 존재.** 다른 장로들은 단편만 이해하거나 리듬·어휘 일부가 누락된 채 재현. VETHARI와 다른 간부진을 구분하는 핵심 차별점 중 하나.

## 7. 표기 규약

- **대문자 전체 표기:** 인-유니버스 L3 원어 원문 (예: KETH'ARUN)
- **한글 병기:** 최초 등장 시 괄호로 (예: KETH'ARUN(케스아룬))
- **번역 표기:** 인간 문서 내에서는 번역명 우선 (예: "수도 / KETH'ARUN")
- **인간 측 코드명이 따로 있는 경우:** 코드명 우선, 원어 괄호 병기 (예: EXUVIA (VETHARI))
