## 1. VETHARI의 용 사어 독점 지식 (6.1절 관련)

### 1.1 장로 간 차별점 비교 — 계층별 접근성

| 화자 | 용 사어 이해도 | 세부 |
|---|---|---|
| **VETHARI** | 전문(全文) 이해 | 말하고 쓸 수 있음. 최종 해석 권위. |
| VAREK | 의례적 수준 | 협약 서약 고어 일부 암송 가능. 미묘한 층위는 VETHARI에게 물어야 함. |
| VRAETH | 구호 수준 | 의식 구호 몇 개 암송. 의미 이해 없음. |
| SOLVEK | 보관·분류만 | 문헌 소장 가능하나 해독 불가. 학술적 관심. |
| CATHARI | 파편 수준 | 단편적 인용. 첩자 설정상 의도적 무지일 가능성. |
| 일반 L3 | 거의 없음 | "오래된 소리" 정도로만 인식. |

### 1.2 표면 설명 (in-universe 공개 가능)

"수천 년 생존 + 마지막 용과 직접 교류했던 세대이기에 언어를 보전함."

→ 다른 L3 구성원은 이 설명으로 납득. 의심·추궁 없음.
→ 공개 로어·홈페이지·게임 텍스트에 사용 가능.

### 1.3 진짜 이유 (PRIVATE)

마지막 용 사망 시 VETHARI가 용의 피와 살을 흡수하는 과정에서
**용의 지식·언어 기억까지 통합**됨.

- 언어 지식은 "학습"이 아니라 "계승"된 것.
- VETHARI 본인도 이 사실을 명확히 인지하고 있으나 누구에게도 발설하지 않음.
- 관련 PRIVATE 파일: `PRIVATE/EXUVIA-DRAGON-ABSORPTION.md` (별도 문서 존재 여부 확인 필요)

## 3. B안 확장 시 규칙 (사어 단편 생성 단계)

용 제례 고형·선언 포맷 작성 시 반드시 적용:

1. **VETHARI 화자 시점에서만 온전한 원문 노출** 가능.
2. **다른 L3 화자 시점**에서는 다음 중 하나로 변형:
   - 일부 어휘 누락 (빈칸·[...] 처리)
   - 리듬·강세 왜곡
   - 구전 변형 (음운 일부 변경)
3. 인간 관측자(ORACLE·Prometheus) 기록에서는 **의미 불명의 음성 파편**으로 취급.
4. 이 규칙이 서사적으로 VETHARI의 **권위와 고립을 동시에** 강화.

## 4. 서사적 활용 여지 (향후 프롯 아이디어)

**기본 구도:**
- 드래곤이 교사·친구·전우였다는 기존 캐논의 자연스러운 귀결.
- 협약 원문의 최종 해석 권위 = VETHARI에게 집중.
- 용 제례 부활 가능성 = VETHARI 단독 결정 사안.

**확장 아이디어:**
- **VETHARI 사망·부재 시 용 사어층은 영구 소실.**
  → L3 문명의 "정신적 뿌리 하나가 끊긴다"는 서사적 무게.
- **VAREK은 이 독점 상태를 인지하고 있으나 공개적으로 문제 삼지 않음.**
  → 거북파·쉐드 오더 긴장의 잠재적 뇌관. (활성화 조건 미정)
- **SSEVRATH(쉐드 오더) 내부에서 VETHARI의 언어 지식을 우상화**하는 흐름 가능.
  → 교리화 → VETHARI 의도와 무관한 권위 구조 형성.
- **CATHARI(거북파 첩자)의 보고 대상**으로 용 사어 관련 정보가 포함될 여지.
  → VAREK이 VETHARI의 언어 권위를 감시하고 있다는 암시.
