## SPEC-003: Brood Drone

- **위협:** DANGER (집단 시)
- **출현:** Ashfall City, Philadelphia Zone 외곽
- **이미지:** ✅ brood-closeup

**설명:** 군체 하위 개체. 하나는 약하다. 문제는 하나인 적이 없다는 거다.

**외형:** 인간 60% 크기. 외골격 구조. 단안(單眼). 갈고리 앞다리.

**행동:** 독립 의지 없음. 정찰/수집/방어 수행. **분리 시 12시간 내 기능 정지.** 하나 쓰러지면 나머지 즉시 대형 재편. 집단 반응 속도 인간 초월.

**격리:** 단독 위협 낮음. 집단 출현 시 즉시 후퇴. 군체 통신 교란 장비 효과적.

**기록:**
- LOG-003A: Ashfall 지하 터널 약 200개체 집단 관측. — Permafrost Unit

## SPEC-005: Shell Walker

- **위협:** DANGER
- **출현:** Philadelphia Zone 외곽
- **이미지:** —

**설명:** TS-Ω 군체의 이동형 하위 개체. 거북이를 인간 크기로 확대한 형태.

**외형:** 등껍질 표면에 발광 문양 — 군체 통신 수신부 추정.

**행동:** 단독 행동 불가. 항상 **2~5개체 편대 이동.** 군체 통신 범위 외 유인 시 기능 저하. 분리 후 **24시간 내 기능 정지.**

**격리:** 등껍질 통신 기관 우선 파괴. 군체 범위 밖으로 유인.

## SPEC-011: Shell Talker (쉘 토커)

- **위협:** HIGH
- **출현:** Philadelphia Zone 외곽, 감염 구역 거주지 잔해 인근
- **이미지:** —

**설명:** 성인 남성 크기의 긴목 거북 변이체. TS-Ω 군체에 소속되어 있으나, 다른 H-TYPE과 근본적으로 다르다 — **독립적 판단이 가능한 군체 사냥꾼이자 현장 지휘 개체.** 군체의식을 공유하되, 명령을 받지 않는다. 스스로 사냥하고, 스스로 판단하며, **주변 하위 개체를 지휘한다.** 죽은 사람의 목소리로 말을 건다. 대답하면 안 된다.

**H-TYPE 내 특수 위치 — "장군 개체":**
TS-Ω Core는 심해에 있다. 거리가 멀수록 군체 통신 신호는 약해지고, 하위 개체들(Brood Drone, Shell Walker)의 반응이 둔해진다. Shell Talker는 이 문제를 해결하는 **현장 중계 지휘관**.

- **지휘:** Shell Talker가 존재하는 반경 내의 Brood Drone, Shell Walker에게 **실시간 전술 명령** 가능. Core의 대략적 의지를 받아 현장 상황에 맞게 독립적으로 번역·실행.
- **중계:** TS-Ω Core의 군체 신호를 수신하여 **증폭·재전송**. Shell Talker가 있는 구역의 하위 개체들은 Core와 직접 통신할 때보다 반응 속도와 정밀도가 대폭 상승.
- **독립 판단:** Core가 전달하는 것은 "방향성"(이 구역을 확보하라, 이 대상을 추적하라). Shell Talker가 하는 것은 **"전술"**(어떻게 확보할지, 누구부터 잡을지, 언제 후퇴할지).
- **사냥:** 지휘와 별개로 독립 사냥 수행. Brood Drone이 몰이를 하고, Shell Talker가 유인과 기습으로 마무리하는 **협동 사냥** 패턴도 관측됨.
- **군체에서 분리 시:** 지휘 기능 상실 (중계할 신호가 없으므로). 그러나 **사냥 능력은 완전 유지**. 분리된 Shell Talker = 지휘권 없는 단독 포식자.

→ TS-Ω Core가 "왕"이라면, Shell Talker는 **"전장의 장군"**. Brood Drone은 "병사", Shell Walker는 "정찰대".

**외형:**
- 체장 약 1.6~1.8m. 긴목 거북 형태. 목 길이만 0.7~1m.
- 껍질 표면에 따개비 유사 다수 구멍(생체 포트). 자극 시 **촉수 돌출** — 길이 2~3m, 흡착 기관.
- 목 표면에 인간 성대 유사 진동 기관. 음성 모방의 물리적 기반.
- 체색: 어두운 회녹색. 축축한 표면. 야간/저조도 환경에서 시각 탐지 어려움.

**사냥 행동:**
- **음성 모방(Voice Mimicry):** 과거에 포획·흡수한 희생자의 음성 데이터를 저장. 이전 희생자의 목소리, 말투, 특정 문장을 재생하여 새 대상 유인. "도와줘" "여기야" "괜찮아, 이리 와" 등 구조 요청 또는 안심 유도.
- **사냥 판단:** 독립적으로 유인 대상을 선택. 무장 여부, 인원수, 경계 수준을 관찰한 후 가장 취약한 대상을 골라 유인. **지능적 선별 사냥.** 위협이 크다고 판단하면 유인을 포기하고 잠복 상태로 전환.
- **매복:** 폐건물, 하수구, 어두운 구석에 웅크린 채 장시간 대기 가능. 인내심이 있다 — 며칠을 기다리기도 함.
- **기습:** 유인 성공 시 긴 목을 이용한 **무음 기습**. 사정거리 1.5m 내 진입 시 0.5초 내 머리/상반신 포착.
- **촉수 포박:** 기습과 동시에 껍질 촉수 사출. 대상 이동 불가 → 서서히 흡수.
- **학습:** 사냥 실패 시 같은 전술을 반복하지 않음. 실패 패턴을 기억하고 **다음 사냥에서 전술을 변경**. 이것이 단순 포식자와 Shell Talker를 구분하는 핵심 — 학습하는 사냥꾼.

**위협 사유: HIGH**
- Brood Drone(DANGER)보다 상위. 이유: 기만 + 독립 판단 + 학습 + **현장 지휘**.
- Shell Talker가 있는 구역의 Brood Drone은 반응 속도와 전술 정밀도가 **눈에 띄게 상승**. Shell Talker를 제거하면 해당 구역 하위 개체의 조직력이 급격히 저하.
- 군체 교란 장비로 무력화 불가 — 분리되어도 사냥 기능 유지.
- 인간의 공감 본능을 공격 벡터로 사용.
- 야간/폐건물/하수구 등 시야 제한 환경에서 위협 극대화.
- **전술적 우선 제거 대상** — Shell Talker 1체 제거 = 해당 구역 수십 체의 조직력 붕괴.

**격리:**
모르는 목소리에 반응하지 마라. **아는 목소리에는 더더욱 반응하지 마라.** 감염 구역에서 동료 음성을 들으면 무전으로 위치 먼저 확인. 확인 불가 시 접근 금지. 조우 시 목 사정거리(1.5m) + 촉수 범위(2~3m) 밖 유지. 군체 교란 장비는 **이 개체에 효과 제한적** — 독립 기능 유지.
