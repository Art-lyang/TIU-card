# TIU-KARUNTAL — 카룬탈 문명 설정
> 최종 업데이트: 2026-03-29

## 1. 개요 ✅ 확정

- 명칭: **KARUNTAL (카룬탈)** — "경계의 문" (Karun 관문 + Tal 문턱)
- 시대: 초고대 (추정 5,000~10,000년 전). 정확한 연대측정 불가.
- 규모: **불명**. 유적만 남아서 전체상 파악 불가.
- 멸망 원인: **불명**. 무엇이 그들을 지웠는지 아무도 모름.
- 현존 유적: 소바리 밀림 내부 사원군. 다른 대륙에는 흔적 찾을 수 없음.
- 현재 인지 주체: **없음**. ORACLE, Observer, 프로메테우스, L3 — 누구도 카룬탈의 정체를 모름.

---

## 2. 건축 ✅ 확정

**양식:** 마야 문명과 유사하나 정확히 일치하지 않음.
- 계단식 피라미드 구조. 마야 쿠쿨칸 신전과 유사한 기본 형태.
- 비율 차이: 계단이 마야보다 가파르고 최상단이 뾰족하게 수렴.
- 석재 접합: 잉카식 정밀 석조. 접착제 없이 완벽 맞물림.
- 입구 양쪽: 이집트 오벨리스크 유사 단일 석주.

**재질:** 현지 채취 불가능한 석재 포함. 가장 가까운 동일 석재 산지 = 수천 km. (게이트 기술 암시)

**규모:** 소바리 밀림 내 약 12~15기 추정. 밀림에 완전히 뒤덮임. 일부 지하 매몰.

**보존:** 5,000~10,000년 경과 대비 비정상적 양호. 석재 풍화가 예상치의 ~30%. 공간 왜곡의 부수 효과로 물리적 열화가 느려진 것으로 추정.

---

## 3. 문양과 비문 ✅ 확정

- 벽면, 석주, 계단 측면에 **고밀도 문양** 각인.
- 문자 체계인지 장식인지 판별 불가. 현존 고대 문자와 불일치.
- 부분적 유사성: 마야 상형문자(블록 배열), 수메르 쐐기문자(기호 형태), 인더스 문자(해독 불가 공통점).

**디자인:**
- 마야 블록형 배열 + 기하학적 패턴 혼합.
- 직선/곡선 교차. 프랙탈적 반복 — 확대하면 내부에 더 작은 패턴 중첩.
- 핵심 모티프: "문/경계" — 사각형 안의 사각형, 동심원, 교차 수직선.

**배치 규칙:**
- 모든 사원의 **입구와 경계점**(계단 꺾이는 곳, 방과 방 사이)에 반복 배치.
- 게이트 아치에 가장 복잡한 버전. 제단에 두 번째.
- → "문/경계"와 관련된 기능적 배치. 상세: TIU-KARUNTAL-ARTIFACTS.md

## 4. 배치 구조

- 사원군은 무작위가 아닌 **특정 기하학적 패턴**으로 배치.
- 상공에서 보면 하나의 도형을 이루나, 밀림 캐노피 때문에 위성으로도 확인 불가.
- 가장 큰 사원(중심 사원)이 공간 왜곡 중심점과 거의 일치.
- 중심→외곽: 사원 규모 감소 + 공간 왜곡 약화.
- → "무언가를 둘러싸는" 또는 "무언가로부터 퍼져나가는" 구조.

## 5. 알려지지 않은 것 — 카룬탈의 심연

### 정체
국가인가, 종교 집단인가, 기술 문명인가? 유적만으로 판별 불가.
군사/주거/농경 흔적 없음. 사원이 주거 겸용? 게이트로 자원 조달?

### 인구
매장지/묘지 미발견. 생활 쓰레기/도구 거의 없음. "살았던 흔적"이 아닌 "지은 흔적"만 존재.
→ 물리적으로 이동하지 않고 인지적으로 이동한 문명? (TIU-KARUNTAL-ARTIFACTS.md 참조)

### 멸망
전쟁/파괴 흔적 없음. 화재, 공성, 학살의 증거 없음. 사원은 파손이 아닌 **방치**에 의해 퇴화.
"사라졌다"기보다 **"떠났다"**에 가까운 상태.
- 게이트를 통해 어딘가로? 방문자를 따라?
- 게이트 기술 오작동으로 소멸?
- 방문자의 떠남이 존립 기반을 무너뜨림?

> **카룬탈은 끝나지 않았다 — 다만 여기에 없을 뿐이다.** 이것조차 확인 불가.

## 6. 카룬탈인 ✅ 확정

- 부서진 벽화에 **일반적인 인류 형태** 확인.
- 해당 지역(서아프리카) 인류 형태와 일치 추정.
- 벽화에서 관측 가능:
  - 특정 의례 행위 장면 (자세 판별 가능, 행위 내용 → 벽화 상세 참조)
  - 인물 위/주변에 기하학적 문양 — 문양이 인물보다 크게 묘사
  - 아치형 구조물 앞에 선 인물 — 게이트 앞의 카룬탈인
- 안료 분석 시 정확한 연대측정 가능성.

## 7. 방문자와의 관계 ✅ 확정

- 카룬탈은 방문자와 접촉/숭배했을 가능성. 사원이 그 증거.
- 방문자의 영향이 카룬탈 사원을 통해 물리적 공간에 각인.
- 카룬탈 소멸 후에도 각인은 남아 밀림의 물리법칙을 왜곡 중.

**구조:**
```
방문자 → 카룬탈 (접촉/매개) → 사원 건설 → 공간 각인
                                              ↓
                              카룬탈 소멸 후에도 잔여 영향 지속
                                              ↓
                              EV-Σ 사멸 규칙 무효화 + 공간 왜곡
                                              ↓
                              소바리 주민 금기 10조 (경험적 적응)
```

카룬탈은 **매개자**. 방문자와 현재 소바리 사이를 잇는 다리.

## 8. 다른 대륙과의 연결 ✅ 확정

**다른 대륙에서 카룬탈 유적: 흔적 찾을 수 없음.**

양식 유사성만 존재:
- 메소아메리카 (마야) — 가장 강한 유사성
- 이집트 — 오벨리스크형 석주
- 잉카 — 정밀 석재 접합
- 인더스 — 해독 불가 문자

→ 소바리가 카룬탈의 **유일한 물리적 증거**.

### 기존 TIU 설정과의 잠재적 교차점
- Saharan Subsurface Grid — 카룬탈 네트워크 잔해?
- L3 지하 통로 — 사원 하부에 비활성 고대 통로로 일부 연결. 양쪽 모두 인지 못함. ✅ 확정
- Antarctic Gate / 바티칸 — 극도의 추측 단계. 미확정.

→ 서사가 필요할 때만 활성화. 지금은 가능성으로만 존재.

## 9. ORACLE/Observer 시점

**ORACLE:** 카룬탈 존재를 모름. 데이터 0. 확보해도 "설명 불가 고대 유적"으로만 분류.
**Observer:** 방문자를 인지하므로 카룬탈 성격 추론 가능. 그러나 **관심 없음**. 방문자 부재 + 카룬탈 멸망 = "빈 영역".

---

## 10. 서사적 가치

1. **세계의 깊이** — 시간축이 수천 년 전으로 확장
2. **Observer의 한계** — 전지적 존재도 모르는 것, 관심 두지 않는 것이 있음
3. **우주적 암시** — 방문자 → 카룬탈 → 사원을 통해 지구 밖 존재 암시. 직접 등장 없이.
4. **인간의 잠재력** — 인간 문명이 차원을 넘나드는 기술 보유. 인류가 도달 가능한 극한.
5. **미스터리 엔진** — "왜 사라졌는가" "게이트는 어디로" "방문자는 무엇을 원했는가"
