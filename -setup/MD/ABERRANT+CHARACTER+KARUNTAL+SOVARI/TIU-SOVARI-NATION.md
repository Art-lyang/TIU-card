## 4. EV-Σ 변칙 현상 ✅ 확정

**확정된 환경 규칙:** 고온 → 구조 붕괴 (사멸)
**소바리:** 열대 = 고온. **EV-Σ는 사멸해야 한다. 그런데 죽지 않았다.**

**원인:** EV-Σ가 열 내성을 획득한 것이 아님. 사원 주변 환경 자체가 방문자의 잔여 영향으로 변질. 고온이지만 고온의 규칙이 완전히 적용되지 않는 구역.

바이러스의 문제가 아닌 **장소의 문제**. 사원에 가까울수록 왜곡 강함. 외곽으로 갈수록 약해짐.

---

## 5. 방문자 (THE VISITOR) ✅ 확정

- TIU 4계층 구조 **바깥**의 존재. 지구의 존재가 아님.
- 현재 지구에 없음. 실존 여부 자체 확인 불가. 생사 불명.
- 일종의 **외신(外神)**. 떡밥/암시로만 존재.
- Observer는 인지하고 있으나 ORACLE에 정보 미전달. 소바리를 **"남의 영역"**으로 인식.
- 방문자의 스케일: Observer와 동급 이상 암시.
- ORACLE은 방문자를 모름 → 소바리 이상 현상을 영원히 "설명 불가"로 분류.

## 6. 불가사의 현상 ✅ 확정

**유형:** 공간/물리법칙 이상
- 중력 미세 변화
- 방향감각 상실 (나침반/GPS 왜곡)
- 거리 왜곡 (같은 경로, 다른 체감 거리)
- 음향 이상

**강도:** 미묘함. 며칠 머물러야 겨우 느끼는 수준.
주민들은 태어나면서 적응. 외부인은 잠깐 지나가면 감지 못함. 전문 장비로 정밀 측정해야 수치 이상 포착.

**기존 TIU 초자연과의 관계:**

| 현상 | 계열 | 성격 |
|------|------|------|
| SERAPH 공간 재작성 | Observer | 의도적, 순간적, 극한적 |
| **소바리 공간 왜곡** | **방문자 잔여** | **항상적, 미묘, 비의도적** |

→ Observer 계열과 **완전 무관**. 질적으로 다른 기원.

## 7. 소바리 밀림의 금기 10조 ✅ 확정

세대를 거쳐 경험적으로 축적된 생존 규칙. 사원과 관련 있으나 숭배에서 비롯된 것 아님.

**제1조 — 돌의 숨결을 거스르지 마라**
사원 주변에서는 바람 방향으로만 이동. → 역풍 방향 = 공간 왜곡 최강 구간.

**제2조 — 해가 머리 위에 있을 때 돌 사이를 지나지 마라**
정오(11~13시) 사원 구조물 통과 금지. → 태양 최고점 = 중력 왜곡 최강.

**제3조 — 강이 느려지는 곳에서 물을 마시지 마라**
유속 급감 구간의 물 금지. → 왜곡 구역 통과 하천 = EV-Σ 잔존.

**제4조 — 밤에 셋 이상 모여 불을 피우지 마라**
큰 불 = "밀림이 깨어난다." → 열원이 왜곡 온도 균형 교란 → 비정상 포자 방출.

**제5조 — 걸음을 세어라. 수가 맞지 않으면 돌아가라**
걸음 수 변화 = 왜곡 강화 신호. → 더 깊이 가면 방향감각 완전 상실.

**제6조 — 새가 울지 않는 구역에 머물지 마라**
새소리 소실 = 음향 왜곡 구역. → 공간 왜곡 중심부 근접.

**제7조 — 같은 나무를 두 번 보면 멈춰라**
경로 휘어짐 → 원점 회귀. → 정지 상태에서 왜곡 영향 최소화.

**제8조 — 뿌리가 땅 위로 나온 나무 아래에서 자지 마라**
EV-Σ 융합 나무. 장시간 노출 → Phase 0 수준 일시적 인지 교란.

**제9조 — 우기 첫 비가 내리면 3일간 사원에 가까이 가지 마라**
기온/습도 급변 → 왜곡 패턴 일시 교란 → 체감 가능 수준으로 강화. 3일 후 복귀.

**제10조 — 돌에 새겨진 것을 따라 그리지 마라**
실제 원인: **미확정**. "따라 그린 자는 꿈에서 문을 본다." 카룬탈 게이트 기술과 가장 직접적 연결.
