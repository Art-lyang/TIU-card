## 1. 게이트 기술 개요

카룬탈의 핵심 기술. "경계의 문"이라는 문명 이름의 근거.

**핵심 공식:**
```
유물 (좌표) + 문양 (열쇠) + 인간의 의식 (동력) = 게이트 활성화
```

- **유물** — 공간좌표를 확정하는 장치. 목적지를 고정.
- **문양** — 게이트를 여는 열쇠. 사원 벽면/석주/제단에 각인.
- **인간의 의식** — 동력원. 꿈꾸는 자의 인지 에너지가 게이트를 가동.

→ 기계가 아닌 **인지적 장치**. 물리적 이동이 아닌 의식을 매개로 한 기술.
→ 현대인이 해도 작동 = 카룬탈 전용이 아닌 **인류 보편적 메커니즘**. 카룬탈은 이것을 "발견"한 문명.

### 간접 증거
- 현지 채취 불가능한 석재 (원거리 운반 필요)
- 여러 대륙 고대 문명의 부분적 유사성 (기술 전파)
- 사원 입구/경계점에 집중된 반복 문양 (기능적 배치)
- L3 지하 통로 연결 — 비활성. 양쪽 모두 인지 못함. ✅ 확정
- 제10조 금기: "문양을 따라 그리면 꿈에서 문을 본다"

### 사원의 기능 추정
1. **게이트 터미널** — 차원/공간 이동 출입구. 현재 비활성.
2. **앵커(닻)** — 방문자의 영향을 물리 공간에 고정. 사원이 있기에 왜곡 유지.
3. **관측소** — 방문자를 향해 "보는" 장치?
→ 확정 안 함. 서사에서 점진적 암시.

## 2. 중심 사원 내부 ✅ 확정

### 구조 추정
- **전실** — 입구에서 이어지는 좁은 통로. 벽면 문양 최고 밀도.
- **중앙실** — 넓은 공간. 천장 높음. 중앙에 제단 + 뒤편에 게이트 아치.
- **하부** — 지하로 이어지는 계단. L3 통로 연결점 가능성.

### 제단
- 중앙실 한가운데. 단일 석재로 깎아낸 직육면체.
- 표면에 가장 복잡하고 정교한 문양.
- 제단 위에 오목한 자국 — 공간좌표 유물이 놓여 있던 흔적. 현재 비어 있음.

### 게이트 아치
- 제단 뒤편 벽면의 아치형 구조물 잔해. 석재 프레임만 남음.
- 아치 내부: 현재 그냥 벽. 작동 안 함.
- 프레임 접합부에 카룬탈 문양 최고 밀도 각인.
- 아치 주변 공간 왜곡이 사원 내에서 가장 강함.

## 3. 공간좌표 유물 ✅ 확정

- **형태:** 구형. 크리스탈 재질. 내부에 붉고 푸른 에너지가 묘사됨 (벽화 기준).
- **기능:** 게이트의 목적지 좌표를 고정. 유물이 제단에 놓이면 게이트 아치가 특정 시공간으로 연결.
- **현재:** 제단 위에 없음. **분실인지 카룬탈인이 가져갔는지 알 수 없음.**
- **유물 부재의 결과:** 좌표 없이는 문을 열어도 목적지 없음. 꿈을 통한 "관측"은 가능하나 "이동"은 불가.
- **벽화에 기록됨:** 사원 내부 벽화 장면 1에서 유물의 형태와 사용법 묘사.

## 4. 벽화 6장면 ✅ 확정

사원 내부 벽화. 좌→우 연속 서사. 대부분 박락되었으나 복원 가능한 잔해 남음.

### 장면 1 — 공간좌표 유물
인물이 제단 위에 **크리스탈 구체**를 놓는 장면. 유물에서 방사형 선이 뻗어나가 사원 전체를 감싸는 묘사.
→ 해석: 좌표 고정. 유물 설치 = 사원 활성화.

### 장면 2 — 건축
다수의 인물이 석재를 쌓는 장면. **석재 운반 방법이 묘사되지 않음** — 석재가 "이미 거기에 있는" 것처럼 배치.
→ 해석: 게이트로 석재를 목적지에 직접 "출현"시켰을 가능성.

### 장면 3 — 꿈꾸는 자의 의례
인물이 제단 앞에 앉아 눈을 감음. 손 앞에 **현실에서 그린 문양**. 머리 위에 **같은 문양이 빛나는 형태** (꿈 속 문양). 두 문양 사이에 빛의 선이 연결.
→ 해석: 현실 문양과 인지 속 문양의 공명. 게이트 기술의 핵심 원리.

### 장면 4 — 에너지와 게이트
장면 3에서 이어짐. 두 문양 사이의 빛이 선을 따라 **게이트 아치로 흘러 들어감**. 아치 내부가 밝게 빛남 — 활성화. 제단 위 유물도 빛남 — 좌표 고정 상태.
→ 해석: **꿈꾸는 자의 인지 에너지 = 게이트의 동력원.** 유물 = 좌표. 문양 = 열쇠. 의식 = 연료.

### 장면 5 — 게이트 통과
인물들이 빛나는 게이트 아치를 통과. 아치 너머는 현재 밀림과 다른 풍경. 가장 많이 박락된 장면 — 아치 너머 풍경 거의 판독 불가.
→ 해석: 게이트 일상 사용 시절.

### 장면 6 — 실패한 자
인물이 제단 앞에 쓰러짐. 눈을 크게 뜬 채. 주변 인물들이 뒤로 물러남. 쓰러진 인물 머리 위에 **불완전한 문양** — 깨진 선, 끊어진 원. 게이트 아치는 빛나지 않음. 대신 쓰러진 인물에게서 어두운 선이 방사.
→ 해석: **꿈에서 문양을 완성하지 못한 채 문을 본 자.** 인지 구조 붕괴. 제10조 금기의 시각적 증거.

### 벽화 전체 메시지:
```
유물(좌표) + 문양(열쇠) + 의식(동력) = 게이트
        문양 완전 → 통과/관측 가능
        문양 불완전 → 인지 붕괴
```

## 5. 제10조 — "꿈에서 문을 본다" 상세 ✅ 확정

### 과정
```
① 문양을 모사한다 (종이, 땅, 어디든)
        ↓
② 잠이 들면 꿈에서 같은 문양이 보인다
        ↓
③ 꿈 속에서 문양을 완성하면 (그리면)
        ↓
④ 문이 열린다
        ↓
⑤ 문 너머: 과거의 카룬탈을 본다
```

### 꿈에서 보는 것 ✅ 확정

카룬탈이 존재하던 **랜덤한 시간대/위치/시점**을 관측:
- 시점: 제3자 관찰 (유체이탈 시점). 매번 다름.
- 위치: 사원 내부, 외부, 거리, 건축 현장 등. 매번 다름.
- 시대: 건설 중일 수도, 완성 후 일상일 수도. 통제 불가.
- 주요 장면: 건축 / 거리 일상 / 의례 / 밀림 (현재와 다른, 더 밝고 정돈된 밀림)
- 소리 없음. 냄새/촉감 없음. 순수 시각만.
- 기억: 3일 후 "뭔가를 봤다"는 감각만 남음. 단, 건축물/문양은 상대적으로 선명하게 잔존.

### 핵심 규칙

**문양 완성 + 문을 봄:** 과거 카룬탈 관측. 관찰만 가능, 상호작용 불가. 깨어나면 정상.

**문양 미완성 + 문을 봄:** **미쳐버림.** 불완전한 열쇠로 문을 억지로 열면 인지 구조가 감당 못하는 정보 유입. 비가역적 정신 붕괴.

### 소바리 전승

과거 금기를 어긴 사례:
- 문양 완성 → 3일간 잠에서 못 깨어남 → 깨어난 후 정상. "오래된 마을을 봤다"고만 전함.
- 문양 미완성 → 깨어난 후 말을 잃거나 밀림 속으로 들어가 돌아오지 않음.
- 이 사건들이 제10조 금기의 기원.

## 6. 서사 타이밍

```
현재 → 아무도 모름
  ↓
Meridian 접근 → 밀림 탐사 중 사원 발견
  ↓
전문 조사 → 석재/문양/양식 비교. "알려진 문명과 안 맞는다"
  ↓
문양 해독 시도 → 실패. 그러나 "기능적 설계" 단서
  ↓
제10조 위반 → 누군가가 문양 모사. "꿈에서 문을 봤다"
  ↓
방문자 첫 암시 → 공간 왜곡 + 문양의 기능성 + "문을 보는 꿈" = 하나의 그림으로 수렴
        "여기에 누군가가 있었다. 인간이 아닌 누군가."
```
