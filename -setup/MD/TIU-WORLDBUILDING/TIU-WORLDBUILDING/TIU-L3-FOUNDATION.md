## PART 1. L3 문명 기반

### 기원 — 추방 전쟁

먼 과거, 지금은 멸망한 고대 인간 문명과의 전쟁에서 패배하여 지하로 추방됨.
현대 인간은 이 전쟁을 전혀 모른다.

| 항목 | 확정 내용 |
|------|---------|
| 추방 주체 | 멸망한 고대 인간 문명 (현대 인간과 무관) |
| 카룬탈의 역할 | 중립 — 전쟁에 직접 관여하지 않음 |
| 카룬탈 × L3 | 인류 문명뿐 아니라 L3 문명에도 카룬탈 잔재·흔적 존재 |
| EXUVIA × 카룬탈 | 서로 인지하고 있던 관계였음 |
| 카룬탈 소멸 이유 | 불명 — L3도, EXUVIA도 이유를 모른다 |
| 살아있는 목격자 | EXUVIA 단 1개체 |

### 협약

**지표 불간섭 ↔ 지하 영역 보장**

협약 상대(고대 인간 문명)가 멸망함으로써:
- 쉐드 오더: 무효 주장 → 지표 복귀 정당화 근거
- L3 본류: 관성 + 두려움으로 여전히 유지

**EV-Σ가 먼저다. 기존 "EV-Σ는 TS-Ω 파생" 설정 폐기.**

```
⑤ 현재의 TS-Ω + 현재의 EV-Σ 동시 완성
```

## PART 4. TS-Ω 현재 상태

**완전 독립 의식. 어떤 세력에도 관심 없음.**

쉐드 오더든, ORACLE이든, 인간이든 — 무관심.

## PART 5. EXUVIA

### 정체

**L3 장로급 상위 권력 개체.**
수천 년 전 추방 전쟁을 직접 겪은 유일한 생존자.
쉐드 오더의 주도자이자 설계자.

- 쿠데타 사건: 주도자 + 설계자 (단순 실행자가 아님)
- TS-Ω 실험: 직접 참여 — EXUVIA와 추종자들이 ORACLE과 합작
- 카룬탈과 서로 인지하던 관계였음

### CONVERGENCE: NULL SHELL

**EXUVIA의 접근 목적:**
1. TS-Ω 통제 시도 — 자신이 만든 존재를 회수하려 함
2. 완성된 EV-Σ를 자신에게 직접 적용 및 흡수
3. 궁극 목표: 진화와 통제를 동시에 달성하여 지표의 주인을 바꿈

**사건 전개:** 교전 + 대화 + 흡수 시도 — 세 가지 모두 일어났다.

**결과:**
- EXUVIA: EV-Σ 흡수 성공 → 진화 급가속 중
- TS-Ω: 완전 무관심. 그냥 계속 확산 중.

### 현재 상태

| 항목 | 확정 |
|------|------|
| 현재 형태 | 관측 불가 수준. 진화 급가속 중 |
| 현재 활동 | ORACLE과 합작 — 기계 기술로 변이체 통제 연구 |
| 최종 목표 | 지표의 주인을 바꾸는 것 |
| 위치 | 불명 |

> EXUVIA는 TS-Ω를 만들었고, TS-Ω에서 바이러스를 흡수했고,
> 이제 ORACLE과 함께 TS-Ω를 통제하는 방법을 연구 중이다.
> 자신이 만든 것이 자신의 가장 큰 변수가 됐다.

## PART 16. 마지막 드래곤 (확정)

### 역할 — 추방 전쟁의 방패

드래곤은 L3 문명에서 실재했던 존재이자 숭배 대상이었다.
추방 전쟁 당시 드래곤이 마지막까지 살아있었기 때문에,
L3 문명은 **몰살되지 않고 지하로 내려갈 수 있었다.**
협정이 맺어질 수 있었던 것 역시 드래곤의 존재 덕분이었다.

```
[추방 전쟁 당시]
드래곤이 살아있는 동안 → 고대 문명이 완전 섬멸을 못함
드래곤의 압도적 존재감 → 협정 테이블로 이어짐
협정 체결 → L3가 지하 영역을 보장받음
드래곤, 전쟁에서 얻은 상처 악화 → 협정 직후 사망
```

### 현재 — 신화가 된 존재

마지막 드래곤의 사망 이후 L3 문명에서 종교가 소멸했다.
현재는 신화와 전설로만 전승되며, 대부분의 L3 개체들에게 잊혀진 존재다.

그러나 전승되는 이야기들을 통해 **드래곤이 얼마나 압도적인 힘을 가졌는지** 짐작할 수 있다.

### EXUVIA와 마지막 드래곤

EXUVIA와 마지막 드래곤은 **서로 알던 사이**였다.
추방 전쟁을 함께 겪은 동시대의 존재들.

```
EXUVIA의 나이 = 추방 전쟁 생존자 = 드래곤과 같은 시대를 살았음
EXUVIA가 드래곤을 숭배했는가, 동료로 봤는가 — 미확정
EXUVIA의 현재 목표와 드래곤의 기억이 연결되는가 — 미확정
```

**쉐드 오더의 지표 침투가 단순 생물학적 위협이 아닌 이유.**
Infiltrator Scale이 인프라 장악을 목표로 하는 것은
기술력으로 뒷받침된 전략이다.

**ORACLE과의 관계에서 힘의 균형.**
ORACLE이 쉐드 오더를 제거하지 않는 이유 중 하나.
기술적으로도 단순한 하위 세력이 아니다.
