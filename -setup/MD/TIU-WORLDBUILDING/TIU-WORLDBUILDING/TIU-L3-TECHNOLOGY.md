## 03. 에너지원

**지열 + 생체 에너지 복합 사용.**

| 에너지원 | 용도 |
|---------|------|
| 지열 | 주 동력원. 지구 내부 열에너지 직접 추출 |
| 생체 에너지 | 보조 동력. 군체·생물 반응에서 동력 생산 |

두 에너지원이 상호 보완적으로 운용된다.
지열이 끊기는 구역은 생체 에너지로 보완하고,
생체 반응이 불안정한 구역은 지열로 안정화한다.

## 04. 케스아룬 유기 건축

**석재·광물 기반 구조물에 생체 소재가 삽입된 형태.**

기계적 골격 위에 유기 요소가 보강재로 들어가 있다.
완전한 생물체처럼 보이지는 않지만,
건물 일부가 **살아있는 조직처럼 반응**한다.

```
건축 구조 예시:
외벽 — 석재·광물 기반. 수천 년 내구성.
내부 — 생체 소재 삽입. 온도·습도 자동 조절.
연결부 — 유기 섬유 강화. 손상 시 자가 회복 가능.
광원 장치 — 생물발광 소재 + 인공 동력 복합.
```

케스아룬이 수천 년간 유지될 수 있는 이유 중 하나.
건물이 완전히 죽지 않는 구조다.

## 05. Infiltrator Scale 위장 기술

**나노·화학적 피부 변환.**

표면 질감과 색을 변환하여 인간 외형을 유지한다.
골격이나 근육 구조를 바꾸는 것이 아니라
**피부 표면의 물리화학적 변환**으로 위장을 구현한다.

```
위장 원리:
나노 입자 피부층 주입 → 광학적 반응 제어
화학 신호 기반 색·질감 변환
인간 체온·체취 모사 보조 물질 사용

한계:
- UV 계열 특정 광원에서 동공 수직 수축 노출
- 체온이 정상 인간 대비 2~3℃ 낮음 (완전 모사 불가)
- 장기 유지 시 주기적 재처치 필요
```

이 기술이 **완벽하지 않다는 것**이 White Shield 식별의 근거가 됐다.

## 06. 변이체 통제 연구 현황

**중간 단계. 소규모 통제 성공. 대규모는 미달.**

EXUVIA와 ORACLE이 현재 기계 기술 기반으로 협력 중인 연구.
VEIN WARD의 현재 최우선 과제.

### 핵심 장애물 (확정)

**TS-Ω 자체에 대한 통제 권한이 전혀 없다.**
TS-Ω 하위 개체도 통제권 탈취 불가.
EXUVIA의 현재 제어 능력이 TS-Ω에 **아예 미치지 못하는 수준**이다.

```
현재 통제 가능 범위:
일반 변이체 (소규모)  ████░░░░░░ 소규모 일시 통제 성공
TS-Ω 하위 개체       ░░░░░░░░░░ 불가
TS-Ω Core            ░░░░░░░░░░ 접근 자체 불가
```

이것이 쉐드 오더가 무기급 기술을 보류하는 핵심 이유다.
TS-Ω를 통제하지 못한 채 지표 침공을 시작하면
자신들이 만든 존재가 작전 전체를 무너뜨릴 수 있다.

## 07. ORACLE의 기술 기여 방식 — 실제 구조

### 표면 구조 (L3가 인식하는 것)

- ORACLE이 TS-Ω·EV-Σ 실험 데이터를 공유
- L3가 ORACLE 관찰을 통해 기술을 역으로 습득
- 쌍방향 기술 교류처럼 보임

### 실제 구조 (확정)

> **ORACLE은 L3의 역습득을 완전히 파악하고 있다.**
> 그리고 **틀린 정보·불완전한 정보를 의도적으로 섞어서 제공**하며
> L3가 눈치채지 못하는 방향으로 유도하고 있다.

```
ORACLE의 실제 운용:

[L3에게 주는 것]
정확한 데이터 (일부)
+ 불완전한 데이터 (의도적)
+ 방향성이 심어진 데이터 (유도)

[L3가 받아들이는 것]
"우리가 ORACLE에서 뽑아낸 기술"
→ 실제로는 ORACLE이 원하는 방향으로 설계된 것
```

**Ashfall City가 그 사례 중 하나다.**

쉐드 오더는 Ashfall City 실험이 자신들의 계획대로 진행되다
실행 오류로 실패했다고 인식한다.
그러나 실패 자체가 ORACLE이 유도한 결과일 가능성이 있다.

```
[ORACLE의 판단 구조]
쉐드 오더가 역습득한다 → 인지함
막을 이유가 없다 → 어차피 Observer 설계 안에 있음
오히려 활용한다 → 원하는 방향으로 데이터를 설계해서 제공
결과 → 쉐드 오더는 자유의지로 움직인다고 믿지만
       실제로는 ORACLE이 설계한 경로 위에 있다
```
