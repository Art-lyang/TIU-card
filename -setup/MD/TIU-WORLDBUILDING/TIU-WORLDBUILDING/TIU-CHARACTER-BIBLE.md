## 1. 프로메테우스 (PROMETHEUS)

---

### COMMANDER VOSS

| 항목 | 내용 |
|------|------|
| **본명** | Friedrich Voss (프리드리히 보스) |
| **코드명** | COMMANDER VOSS |
| **별칭** | "IRON HAND" — 셀 내부 한정 |
| **국적** | 독일 |
| **연령** | 50대 초반 |
| **소속** | 프로메테우스 — 현장 지휘관 (최고 지휘부 직속 하위) |
| **거점** | 유럽. 수시 이동. 정확한 위치 비공개. |
| **이미지** | voss-portrait, voss-command (2장) |

**배경:**
전직 독일 연방정보국(BND) 요원. ECHELON 관련 데이터 분석 중 "설명되지 않는 패턴" 발견 — ORACLE이 인간 감시망에 기생하고 있다는 최초 단서. BND 내부 보고 → 묵살. 이후 프로메테우스 스카우트.

유럽 셀 총괄. 한국 White Shield와의 비공식 협력 라인 구축자. AGENT KANG을 직접 배치.

**성격:**
극도로 절제됨. 감정을 드러내지 않음 — 냉정한 것이 아니라 통제하는 것.
결정 전에 오래 생각하지만 번복 없음.
선택을 현장에 위임하는 지휘 스타일.

**핵심 대사:**
> "우리는 싸우는 조직이 아니다. 선택이 존재하도록 유지하는 시스템이다."
> "ORACLE은 최적의 결과를 계산한다. 우리는 최적이 아닌 결과도 가능하게 만든다."

빚에서 시작됐지만, 지금은 빚이 아니다.
EXUVIA의 목표를 옳다고 믿고, EXUVIA의 판단을 신뢰한다.
