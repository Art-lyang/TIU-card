## 1. 한국 군사력 전체 프로파일 — 특화형 불균형 강국

### 1.1 기본 포지셔닝

- **전체 규모**: 동아시아 지역 상위권. 글로벌 원정 역량은 제한적.
- **대(對)아베란트 역량**: **세계 최고 수준**. 단일 국가 체계로는 비교 대상 없음.
- **비대칭 구조**: DG-프로메테우스 협력의 부산물. 특정 분야 비대칭 우위.

### 1.2 대(對)아베란트 세계 최고의 의미

- 장비 세대·작전 노하우·생체감지·현장 대응·백신 인프라 전 축에서 선두.
- 타 국가·PMC(메리디언 등)의 대(對)아베란트 기술은 **최소 한 세대 뒤**.
- "한국 변종 EV-Σ 샘플"에 대한 대응 데이터는 한국만 축적 중.
- 외국 기관·연구소가 한국의 대(對)아베란트 데이터 접근을 요청하는 역전된 구도.

### 1.3 일반 영역 (지역 상위권)

- 육군: 규모·편제 탄탄, 현대화 진행 중. 전통 대북 대비 체제 유지.
- 해군: 연안 방어 위주. 원양·원정 능력은 제한적.
- 공군: 동아시아 상위권. 독자 항공전력 개발 역량.
- 특수전: 대(對)아베란트 특화 외에는 평균 수준.

### 1.4 서사적 귀결

- 한국은 "은밀한 거인" 톤 — 다윗 아님, 그러나 글로벌 압도 강국도 아님.
- 특정 위기(아베란트)에서만 대체 불가능한 존재.
- 이 불균형이 외교·메리디언 관계·국제 압력 구도의 근본 지렛대.

## 2. 정규 군사 편제 요약

### 2.1 지휘 체계

- **대통령**: 군 통수권자. White Shield 실체 인지자.
- **국방부 장관**: 군 행정 총괄. White Shield 실체 인지자.
- **합동참모의장**: 작전 지휘. White Shield 실체 인지자.
- **합동참모본부 / 합동작전사령부**: 작전 기획·실행 중추.

### 2.2 3군 요약

- **육군**: 전통 편제 유지. 대(對)아베란트 임무 일부 인계, 그러나 핵심은 특재사로 이관.
- **해군**: 연안 방어·해양 감시·해안 아베란트 대응 지원.
- **공군**: 공중 감시·정밀타격·공군 수송 지원. 특재사 작전에 항공력 파견.

### 2.3 특수전 편제

- 전통 특수전사령부 유지.
- 대(對)아베란트 임무는 **특재사가 독립 수행** — 전통 특전 부대와 분리.

## 3. 국가특수재난변이사령부 — 특재사 / White Shield / SDAC

### 3.1 명칭 체계 (3층)

| 층위 | 명칭 | 사용 맥락 |
|---|---|---|
| **대외·대중 통용** | **White Shield** (한국어: 백색방패) | 뉴스·공공 보도·외신 보도·관용어 |
| **한국 군·정부 내부 공식** | **국가특수재난변이사령부** (약칭: **특재사**, 영문: **SDAC** — Special Disaster & Aberrant Command) | 공식 문서·편제·군 내부 |
| **비공개 실체** | DG↔프로메테우스 직접 협정 체계 | 최고위층만 인지 |

→ 세 명칭은 같은 대상을 가리키나, 맥락별로 지시하는 층위가 다름. 이 언어 분리 자체가 TIU의 "인지 비대칭" 주제를 체현.

### 3.2 공식 편제

- **소속**: 합동참모본부 직속 사령부. 타군 조직 체계와 별개의 독립 사령부 지위.
- **지휘관 계급**: 대장(4성). 사령관은 대통령 직보 권한 보유.
- **규모**: 기밀. 정식 병력 규모·예산 세부는 국방예산서에서도 일괄 기밀 처리.
- **편제 구성** (현 시점 확정):
  - **작전단** — 직접 교전·축출·격리 작전 수행.
  - **정보·감시단** — 생체감지·관측·분석. 프로메테우스 정보 공유의 실무 수신처.
  - **기술·장비단** — DG 방산 부문과의 주 접점. 무기 체계 운용·시험·현장 정비.
  - **의무·생체방어단** — 백신·감염 대응·현장 의무. DG 바이오 부문과의 주 접점.
  - **훈련·교육단** — 대(對)아베란트 전문 훈련 과정 운영.

### 3.3 이중 지휘 구조 (비공개)

- **공식 지휘**: 합참의장 → 특재사 사령관 → 예하 단장.
- **비공식 협의 라인**: DG 방산부문 사장 ↔ 특재사 주요 부서장 간 실무 채널.
  - 무기 개발·보급·전술 교리 협의가 여기서 결정됨.
  - 정부 최고위층은 이 라인의 존재를 인지하며 묵인.
  - 중간급 장교들은 "DG와의 기술 협력 회의" 수준으로 이해.
- **프로메테우스 라인**: 특재사 최고위 3~5명만 직접 접점. 정보·기술 전달은 DG를 경유하는 경우가 대부분.

### 3.4 임무·관할

- **대(對)아베란트 전투·축출 작전** — 국내 발생 위협 대응.
- **아베란트 격리·수송** — 활용 가능 개체 확보·이송.
- **한국방벽 체계 운용** — DMZ + 북·중 국경 접경 변이체·환경 관리 포괄. §4 참조.
- **ORACLE 프록시 축출 지원** — 국정원·방첩사 특수라인과 협력. `TIU-KOREA-GOV.md` §7.3.
- **백신·의료 긴급 대응** — 대규모 감염 확산 시 민간 지원.

### 3.5 인지 범위

- **공개**:
  - "White Shield / 특재사"의 존재, 대(對)아베란트 임무를 수행한다는 사실, 사령관 직위.
- **반공개** (정부·군 내부):
  - 편제 구성, 임무 유형, 일반적 훈련 체계.
- **기밀**:
  - 병력 규모·정확한 예산·작전 세부·장비 세대.
- **최고위층 전용** (실체):
  - DG↔프로메테우스 직접 협정 구조.
  - 프로메테우스의 구체적 기술·정보 공유 범위.
  - 특재사 최고위 3~5명의 프로메테우스 직접 접점.

### 3.6 정보 분류 체계 — SPEC 분류 유통 규칙

**원천**: SPEC-XXX 분류는 **ORACLE 내부 관측·분류 산출물**. 원천 소유자는 ORACLE/Observer 계층.

**한국 내 유통 경로**:

ORACLE → (프로메테우스의 감청·역공학) → 프로메테우스 → DG 카르텔 최상위 → 특재사 최고위 3~5인.

**사용 주체별 구분**:

| 주체 | SPEC 접근 | 실제 사용 용어 |
|---|---|---|
| 최고위층·특재사 최고위·DG 카르텔 최상위 | ✅ 전체 접근 | SPEC-XXX 직접 사용 (기밀 작전 문서 한정) |
| 특재사 중간급 장교 | 🔶 작전 필요 범위 부분 접근 | 작전 브리핑 중 인용, 평시 문서에는 미사용 |
| 국방부 일반 관료·3군·질병관리청 | ❌ | "변이체 유형" 또는 부처 자체 관측 번호 |
| 언론·대중·외신 | ❌ | 일반어 — "대형 변이체", "휴머노이드형", "유형 A/B" 등 |

**위반 리스크**:
- 공공 문서에 SPEC 표기 노출 시 → 정보 라인 역추적 위험. 즉시 회수·재작성.
- 중간급 장교 유출 시 → 축출·재배치 사유. 프로메테우스에 보고 의무.
- 이 규칙의 **존재 자체**가 기밀 — 공공 맥락에서 "SPEC 분류가 있다는 사실"도 공개되지 않음.

**⚠ 창작 작업 규칙** (세계관 제작자 메모):
- 인-유니버스 공공·대중·일반 관료 맥락의 문서·대사·UI에는 **SPEC-XXX 표기 사용 금지**.
- 일반어로 대체: "변이체", "휴머노이드 계열", "대형 개체", "유형 A/B" 등.
- 웹사이트 `protocols.html` 등 ORACLE 시스템 관점 UI는 예외 — 관찰자가 인-유니버스에서 시스템 내부 뷰를 보는 설정이므로 SPEC 노출 정당.

## 4. 한국방벽 — 특재사 운용 기준 요약

**⚠ 방벽 체계의 상세는 `TIU-KOREA-WALL.md`로 분리.** 본 절은 특재사 관점의 요약만 유지.

### 4.1 공식명 및 포괄 범위

- 군 공식 편제명: **국가변이방위선(國家變異防衛線)**, 영문 **NADL** (National Aberrant Defense Line).
- 대중 관용어: **한국방벽 / 방벽**.

- NADL 전 레이어(물리·센서·자동 교전·기동 대응)의 운용 책임은 **특재사 주관**.

## 5. DG-프로메테우스 공동개발 대(對)아베란트 무기

### 5.1 소유·사용 원칙 (확정)

- **소유권**: **공동 자산**. DG와 프로메테우스가 공유.
- **사용권**: **각자 판단** — 양측이 각자 작전 수요에 따라 자유 사용.
- **제3자 이전**: **양자 합의 필수** — 한쪽이 단독으로 타 조직·타 국가에 판매·기증 불가.
- **생산 주체**: 주로 DG 방산부문. 프로메테우스는 핵심 부품·재료 중 일부를 단독 공급.
- **배치 주체**:
  - 한국 영토·특재사 작전 = DG 생산, 특재사 운용.
  - 프로메테우스 글로벌 작전 = 프로메테우스 자체 운용.

### 5.2 기술 세대·종류 (개요)

- **개인화기 계열**: 대(對)아베란트 특화 소화기·자동화기. 일반 탄과 생체파괴탄 혼용 가능.
- **중화기·장갑**: M-TYPE 대응용 중화기, 대형 개체용 화력 체계.
- **생체감지 장비**: 휴대·거치 겸용. 프로메테우스 원천 기술 비중 높음.
- **격리·봉쇄 장비**: 현장 격리막·냉각 시스템(EV-Σ 열 취약성 활용)·생체 봉쇄.
- **백신·의무 체계**: DG 바이오 부문 주도, 프로메테우스 임상 데이터 일부 제공.
  - **치료 시간창 제약**: Phase 0(잠복기, 감염 후 24~72시간) 내 투여만 효과. Phase 1 이후 치료 불가. 프리온형 자기변형 메커니즘의 비가역성 때문.
  - 실전 교리: 감염 의심자는 **혈액검사 → Phase 0 확인 시 즉시 투여 / Phase 1 이상 확인 시 격리·제거 프로토콜**로 분기. 중간 선택지 없음.
  - 이 제약은 특재사의 현장 대응 속도 요구를 극한으로 끌어올리는 근본 원인.

### 🏷 플래그

- 구체 무기 체계 명칭·모델명 미정. 후속 작업에서 카드·미션 연계해 명명 예정.

### 5.3 외부 노출 통제

- **타 국가·PMC 유출 방지**: 공식 수출 전면 금지. 메리디언 등 경쟁 PMC의 역설계 시도 지속 중.
- **역설계 방어**: 핵심 부품에 자기파괴 메커니즘 내장. 무단 분해 시 무력화.
- **정보 유출 사건**: 과거 발생 여부 미정 (서사 슬롯).

### 5.4 글로벌 파급 효과

- 한국이 이 무기 체계를 독점에 가깝게 운용 → 대(對)아베란트 영역에서의 한국 우위 고착.
- 타 국가는 한국에 협력 요청 또는 메리디언 등 민간 PMC에 의존 — 한국이 원치 않으면 접근 불가.
- 한국이 요청을 수락·거부하는 기준은 최고위층 + DG 카르텔 합의로 결정.

## 6. 글로벌 전략 포지션

### 6.1 메리디언 그룹과의 군사적 긴장

- 메리디언은 한국 외 글로벌 시장 장악. 한국 영토 내 활동은 제한적 (주한 외국 기관 대상 등).
- **무력 충돌은 현재까지 없음.** 로비·역설계·정보전 수준.
- 한국 영토에서의 비인가 작전 적발 시 특재사가 즉시 개입할 권한 보유.
- 메리디언 BioAsset Division이 한국 변종 EV-Σ 샘플에 접근하려는 시도는 상시 감시 대상.

### 6.2 미국 ARES Division과의 관계

- **ARES Division = 미국 특수부대**. 한국 부대 아님.
- 한미 대(對)아베란트 공조 차원에서 ARES와 특재사 간 **제한적 합동작전·정보 공유** 채널 존재.
- 그러나 특재사 핵심 기술·프로메테우스 협력 실체는 ARES에도 비공개.
- ARES 관점: "한국은 이상하게 대(對)아베란트 역량이 강한 동맹." — 실체 미인지.

### 🏷 플래그

- ARES-특재사 구체 합동작전 사례 / 인물 연결 — 후속 작업에서 캐릭터 바이블과 연동

### 6.3 중국·일본·역내 관계

- **중국**: 북·중 접경 월경 변이체 문제로 기술적 실무 협력은 있으나 정치적 긴장 상존. 중국은 한국의 기술 우위를 질시·경계.
- **일본**: 자체 대(對)아베란트 역량 강화 중. 한국에 기술 협력 요청하나 한국은 선별적 수용.
- **동남아·인도양**: 프로메테우스 글로벌 작전 권역. 한국 특재사의 직접 관할 아님.

### 6.4 대북 (DPRK Black Zone)

- 현재 한국 정부·군은 DPRK Black Zone 현상을 **EV-Σ 관련 대규모 변이 사태**로 추정 중.
- 실제 원인은 Observer 시공간 능력 부작용 (캐논 진실, 한국 미인지).
- 특재사는 DMZ 방어·관측을 지속하나 북측 내부 개입 작전은 수행하지 않음.
- 대북 정책 논쟁은 `TIU-KOREA-GOV.md` §3 축 심화 시 상술.

## 7. 주요 인물 슬롯 (이름·디테일 미정)

- **특재사 사령관** (대장) — 최고위층 실체 인지자. 대통령 직보 권한.
- **특재사 참모장** — 일상 지휘·행정 총괄.
- **작전단장** — 직접 작전 지휘.
- **정보·감시단장** — 프로메테우스 정보 수신 실무 최전선.
- **기술·장비단장** — DG 방산 접점.
- **의무·생체방어단장** — DG 바이오 접점.
- **DG 방산부문 사장** (`TIU-KOREA-DAEGA.md` §7에서 이미 슬롯 존재) — 특재사와의 비공식 라인 주 담당.
- **프로메테우스 연락관** — 특재사 최고위 접점. 한국 상주 여부 미정.
